개인정보처리방침

앱: 오늘의 운담 (Undam) · 패키지: com.wafflelabs.undam
운영자: 와플랩스 (WaffleLabs)
시행일: 2026-11-07

와플랩스(이하 “운영자”)는 Google Play에 게시하는 앱 「오늘의 운담」(이하 “앱”)에서 처리되는 정보를 아래와 같이 안내합니다.

1. 계정

앱에는 회원 가입·로그인 기능이 없고, 운영자는 이용자 계정을 만들거나 관리하지 않습니다. 운영자는 앱이 이용자 정보를 보내는 자체 서버를 운영하지 않습니다.

2. 기기 안에만 저장되는 정보

  • 프로필: 별명(선택), 생년월일(양력/음력), 태어난 시각(선택), 성별(선택), 출생 지역·거주 지역(앱에 내장된 도시 목록에서 직접 선택). 기기의 GPS·위치 권한은 사용하지 않습니다.
  • 운세·사주·타로·손금·관상·부적·로또 번호 결과와 보관함 기록, 알림·테마 등 설정, 광고 제거 구매 여부 확인 결과, 광고 표시 간격 기록.

앱은 이 정보를 운영자에게 보내지 않습니다. Android 기기 백업(Google 백업)을 켠 경우 이용자의 백업에 포함될 수 있습니다. 다만 앱 0.4.8부터 광고 제거 구매 여부 확인 결과와 광고 표시 간격 기록은 별도 파일에 저장되어 백업과 기기 간 이전에서 제외되며, 이전 버전이 남긴 손금 사진 파일도 제외됩니다. 0.4.8 이전 버전에서 이미 만들어진 백업에는 이 광고 기록이 들어 있을 수 있습니다. 새 기기에서 광고 제거 여부는 Google Play 구매 내역으로 다시 확인됩니다.

3. 카메라·사진(손금·관상)

  • 카메라는 이용자가 손금·관상에서 촬영을 고르고 앱 안내에 동의한 뒤, 처음 사용할 때 Android 권한을 허용한 경우에만 사용합니다. 앨범에서 사진을 고를 수도 있습니다.
  • 사진 속 얼굴·손의 위치(점 좌표)는 앱에 포함된 Google ML Kit 얼굴 검출과 Google MediaPipe 손 랜드마크로 기기 안에서 찾고, 그 비율로 재미용 풀이를 만듭니다. 사람을 알아보거나 인증하는 데 쓰지 않습니다.
  • 앱에는 사진을 운영자 서버나 광고 SDK로 올리는 기능이 없습니다. 관상 사진은 결과를 보는 동안, 손금 사진은 앱이 실행 중인 동안 기기 메모리에서만 다루며 파일로 저장하지 않습니다. 손금은 결과 문구와 측정 비율(숫자)만 기기에 저장됩니다.
  • 다만 이 두 SDK는 사진과 별개로 진단·사용 정보를 Google에 보낼 수 있습니다(5항).
  • 앨범 저장과 공유는 이용자가 직접 고른 경우에만 이루어지며, 공유 카드에는 사진이 들어가지 않습니다.

4. 로또 당첨 결과 갱신

앱은 최신 당첨 결과 파일을 GitHub Pages(GitHub, Inc.)의 고정 주소에서 인증 없이 HTTPS로 내려받습니다. 이때 이름·생년월일·입력값·광고 ID·쿠키는 보내지 않습니다. 다만 일반적인 인터넷 접속처럼 접속 IP 주소, 기기·OS 정보(User-Agent), 요청 시각이 GitHub에 전달되며, GitHub는 방문자 IP를 보안 목적으로 기록·보관한다고 밝히고 있습니다. 운영자는 이 기록을 받거나 열람하지 않으며, 보관 기간 등은 GitHub의 정책을 따릅니다.

GitHub Pages 안내: https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages
GitHub 개인정보처리방침: https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement

5. Google SDK가 처리하는 정보

아래는 각 SDK의 공식 문서에 적힌 내용이며, 해당 정보의 처리와 보관은 Google 개인정보처리방침(https://policies.google.com/privacy)을 따릅니다.

  • Google AdMob(광고)·사용자 메시지 플랫폼(UMP, 동의 관리): AdMob은 광고, 분석, 부정행위 방지 목적으로 IP 주소(대략적 위치 추정에 쓰일 수 있음), 앱 실행·탭 등 상호작용, 앱·SDK 성능 진단 정보, 광고 ID·앱 세트 ID 등 기기 식별자를 자동으로 수집·공유하며 TLS로 암호화해 전송한다고 안내합니다(https://developers.google.com/admob/android/privacy/play-data-disclosure). UMP는 동의가 필요한지 확인하고 이용자의 선택을 기기에 저장합니다. 앱은 프로필·사진·운세 결과를 광고 SDK에 넘기지 않습니다. 광고 제거를 구매하면 광고가 표시되지 않습니다. 파트너 사이트에서의 Google 정보 이용: https://policies.google.com/technologies/partner-sites
  • Google ML Kit(얼굴 검출): 기기 정보(제조사·모델·OS 버전), 앱 정보(패키지명·버전), 사용자·기기를 식별하려는 목적이 아닌 설치별 식별자, 성능 지표, API 설정(이미지 형식·해상도 등), 입력·출력 크기, 기능 버전, 이벤트 종류, 오류 코드를 진단·사용 분석 목적으로 HTTPS로 보내며 제3자에게 넘기지 않는다고 안내합니다(https://developers.google.com/ml-kit/android-data-disclosure).
  • Google MediaPipe(손 랜드마크): 이미지 등 입력 데이터는 기기 안에서 처리되어 Google 서버로 보내지 않으며, 성능·사용 지표(세션·추론 횟수, 하드웨어 성능, 앱 ID, 처리한 미디어의 일반적 특성, 시스템·버전 등)를 성능 측정, 개선, 오남용 탐지 목적으로 Google에 보낸다고 안내합니다(https://developers.google.com/edge/mediapipe/legal/tos).
  • Google Play: 광고 제거 인앱 결제, 앱 업데이트 안내, 앱 도안 자료 내려받기(Play Asset Delivery)는 Google Play를 통해 처리됩니다. 운영자는 카드번호 등 결제 정보를 받지 않으며, 기기에는 구매 여부 확인 결과만 저장됩니다.

6. 알림

운세·로또 알림은 기기에서 예약되는 로컬 알림이며, 알림을 위해 운영자에게 정보를 보내지 않습니다. 앱 설정에서 끌 수 있습니다. 알림 권한은 이용자가 허용한 경우에만 사용합니다.

7. 이용 목적

  • 운세·사주·타로·손금·관상·부적·로또 번호 생성과 기록 보관 등 앱 기능 제공
  • 광고 표시·측정·부정행위 방지(AdMob)
  • 인앱 구매 확인(Google Play)
  • 로또 당첨 결과 갱신(4항)
  • 문의 응대(이용자가 이메일을 보낸 경우)

8. 제3자 제공

4·5항에 적은 서비스 외에 운영자는 이용자 정보를 제3자에게 제공하거나 판매하지 않습니다. 다만 법령에 따른 요청이 있는 경우는 예외로 합니다.

9. 보관과 삭제

  • 기기에 저장된 정보는 이용자가 지울 때까지 기기에 남습니다. 앱 ‘내 정보’ 화면의 ‘모든 로컬 데이터 삭제’로 프로필·기록·설정·손금 결과와 메모리의 사진을 지울 수 있고, 손금 화면의 ‘손금 사진·결과 삭제’로 손금만 지울 수 있습니다. 앱을 삭제하면 앱 안의 정보도 함께 삭제됩니다. 계정이 없으므로 별도의 탈퇴 절차는 없습니다.
  • Google 백업에 포함된 정보는 기기의 Google 백업 설정에서 관리할 수 있습니다.
  • 앨범에 저장했거나 다른 앱으로 공유한 이미지는 해당 앨범·앱에서 직접 지워야 합니다.
  • 운영자 서버에 보관하는 이용자 데이터는 없습니다. 이용자가 보낸 문의 이메일은 문의 처리 완료 후 1년간 보관한 뒤 삭제합니다. 그 전에 삭제를 원하면 같은 주소(yu815kr@gmail.com)로 요청해 주세요.
  • Google·GitHub가 처리하는 정보의 보관은 각 회사의 정책을 따릅니다.

10. 광고 ID와 맞춤 광고

기기 설정(예: 설정 → Google → 광고, 또는 개인정보 보호 → 광고)에서 광고 ID를 재설정·삭제하거나 맞춤 광고를 끌 수 있습니다. 메뉴 이름은 기기·OS 버전에 따라 다를 수 있습니다. UMP가 동의가 필요하다고 판단하면 앱 실행 시 동의 화면이 표시되고, 개인정보 옵션이 필요하다고 판단한 경우 ‘내 정보’에 ‘광고 개인정보 설정’이 표시되어 선택을 바꿀 수 있습니다.

11. 아동

앱은 만 13세 미만 아동을 대상으로 하지 않으며, 운영자는 아동의 개인정보를 의도적으로 수집하지 않습니다.

12. 오락용 고지

앱의 모든 풀이와 로또 번호 생성은 오락·참고용이며 의료·법률·투자 조언이 아닙니다. 로또 번호 생성은 당첨을 보장하지 않으며 앱은 복권을 판매하지 않습니다.

13. 보안

운영자는 합리적인 보호조치를 취하지만, 인터넷 전송의 절대적 안전을 보장할 수는 없습니다.

14. 방침 변경

방침을 바꾸면 이 페이지에 시행일과 함께 게시하고, 중요한 변경은 앱 또는 스토어 설명으로 알립니다.
