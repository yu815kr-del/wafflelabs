2. 이 기기에만 저장하는 정보

  • 찍은 사진·영상(앱 전용 암호화 보관함, Android Keystore 키), 채팅 기록(암호화), 내 프리셋, 잠금 설정, 잠금 실패 시 침입자 사진(설정한 경우, 앞 카메라 한 장, 이 기기에만), 짝 개인키·공유 키(Keystore로 감쌈), 마지막 통화가 끝난 이유(짝 키로 감싸 저장, 짝 해제 시 삭제).
  • 뷰티 보정용 얼굴 검출(ML Kit)은 기기 안에서만 돌아갑니다. 앱은 얼굴 데이터를 저장하거나 서버로 보내지 않습니다. ML Kit는 Google 라이브러리이며, Google이 기술·사용 통계를 처리할 수 있는지 여부는 Google 개인정보처리방침을 따릅니다.
  • 앱 백업과 기기 옮기기에서 앱 데이터는 제외되도록 설정되어 있습니다(allowBackup=false, 데이터 추출 규칙으로 백업·전송 제외).
  • 짝에게 받은 원본은 사용자가 받으면 휴대폰 앨범의 ‘둘만의렌즈’ 폴더에 저장됩니다. 이 파일은 휴대폰 앨범에 있으므로, 짝을 해제하거나 앱을 지워도 자동으로 지워지지 않습니다. 갤러리에서 직접 지울 수 있습니다.

3. 사진·영상 원본과 통화 (서버를 거치지 않음)

  • 원본 사진·영상과 영상·음성 통화는 두 휴대폰이 직접(WebRTC P2P) 주고받으며, 운영자 서버에 원본을 올리지 않습니다. Firebase Storage는 쓰지 않습니다.
  • 앱 ↔ Firebase 구간은 TLS(HTTPS)로 암호화됩니다. 채팅·썸네일·연결/통화 신호의 내용은 두 휴대폰만 아는 짝 키(X25519 키 교환 + HKDF → AES-GCM)로 봉인한 종단간 암호화입니다. 서버(운영자 포함)는 내용을 볼 수 없습니다.
  • 사진·영상 원본은 WebRTC(DTLS) 위에서 다시 짝 키로 16KB 조각마다 AES-GCM 암호화하고 SHA-256으로 확인합니다.
  • 영상·음성 통화 미디어는 WebRTC 표준 암호화(DTLS-SRTP)로 휴대폰끼리 직접 전달됩니다.
  • 상대가 오프라인이면 보내는 휴대폰 안의 암호화된 대기함에 두었다가, 둘 다 온라인일 때 보냅니다.
  • 연결을 위해 Google 공개 STUN 서버(stun.l.google.com:19302, stun1.l.google.com:19302)를 사용합니다. STUN 서버는 연결 주소를 알려 주는 용도로 기기의 공인 IP 주소와 포트를 보게 됩니다(내용은 보지 않습니다). TURN(중계) 서버는 쓰지 않습니다.
  • 직접 연결 특성상 짝 상대 휴대폰도 내 IP 주소를 알 수 있습니다.

4. 알림

앱은 FCM(푸시)을 쓰지 않습니다. firebase-messaging 라이브러리와 푸시 토큰이 없습니다. 앱이 켜져 있으면 Firestore 실시간 수신으로 바로 반영되고, 꺼져 있으면 WorkManager가 약 15분마다 확인해서 기기 안에서 알림을 띄웁니다(‘최대 15분 늦을 수 있어요’. 절전 상태면 더 늦을 수 있습니다). 알림에는 메시지 본문을 넣지 않습니다. 받는 쪽 앱이 꺼져 있으면 전화는 울리지 않고 부재중 알림만 옵니다.

7. 이용자의 권리와 삭제

  • 앱에서 짝 해제: 서버의 짝 기록과 하위 데이터(메시지·썸네일·신호·접속 표시 등)가 모두 지워지고, 두 휴대폰의 대화 기록과 짝 키도 지워집니다. Firebase 익명 계정은 남아 있습니다.
  • 이 기기의 앱 데이터: 앱 삭제 또는 앱 데이터 삭제로 지워집니다(백업 제외). 다만 휴대폰 앨범 ‘둘만의렌즈’에 저장된 받은 원본은 남습니다.
  • 앱을 지우기 전에 짝을 해제하지 않으면, 서버의 짝 기록은 상대가 해제하거나 운영자에게 삭제를 요청할 때까지 남을 수 있습니다.
  • 자세한 절차는 데이터 삭제 안내를 봐 주세요. 열람·정정·삭제·처리 정지는 yu815kr@gmail.com으로 요청할 수 있습니다.
